# Nitara's World

A playful Next.js personal website for Nitara.

## Run
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000

## Deploy
Push this folder to GitHub and import the repository into Vercel. Vercel will build and host it with HTTPS.

## Add photos
Replace the placeholder photo blocks in `app/page.tsx` with Next/Image components pointing to files in `public/photos/`, or connect a CMS later.
